# Media Finder — Android MVP

Android-приложение для единого поиска фото и видео по бесплатным стоковым источникам.

## Версия 0.2
- Pexels — фото и видео
- Pixabay — фото и видео
- Единое поле поиска
- Фильтр «Все / Фото / Видео»
- Параллельный поиск по источникам
- Русская локаль поиска
- Избранное с сохранением на устройстве
- Открытие оригинальной страницы источника
- Нижняя навигация «Поиск / Избранное / Премиум»
- Заготовка интерфейса для будущего премиум-раздела

Pexels официально предоставляет API для доступа к библиотеке фото и видео. Для видео используется endpoint `/v1/videos/search`. citeturn0search2turn0search3

Pixabay предоставляет REST API для поиска изображений и видео. В документации указаны отдельные endpoints для изображений и видео, а также требования по атрибуции источника при отображении результатов. citeturn0search0

## Стек
- Kotlin
- Jetpack Compose
- Retrofit
- Coil

## Запуск
1. Откройте репозиторий в Android Studio.
2. Получите API-ключ Pexels и Pixabay.
3. В `app/build.gradle.kts` укажите ключи в `PEXELS_API_KEY` и `PIXABAY_API_KEY`.
4. Запустите приложение на эмуляторе или Android-устройстве.

## Важно про ключи
Не публикуйте реальные API-ключи в GitHub. Сейчас в проекте оставлены пустые значения. Для production-версии API-запросы лучше вынести на собственный backend.
