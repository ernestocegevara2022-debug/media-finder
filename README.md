# Media Finder — Android MVP

Android-приложение для единого поиска фото и видео по бесплатным стоковым источникам.

## Подключено в MVP
- Pexels — фото и видео
- Pixabay — фото и видео
- Единое поле поиска
- Фильтр «Все / Фото / Видео»
- Сетка превью

## Стек
- Kotlin
- Jetpack Compose
- Retrofit
- Coil

## Запуск
1. Откройте репозиторий в Android Studio.
2. Получите API-ключи Pexels и Pixabay.
3. В `app/build.gradle.kts` укажите ключи в `PEXELS_API_KEY` и `PIXABAY_API_KEY`.
4. Запустите приложение на эмуляторе или Android-устройстве.

## Безопасность API-ключей
В MVP ключи используются локально только для прототипирования. Перед публикацией в Google Play рекомендуется вынести API-вызовы на собственный backend, чтобы секреты нельзя было извлечь из APK.
