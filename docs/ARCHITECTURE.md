# Архитектура Media Finder

## Цель
Единый Android-поиск медиа с разделением источников на бесплатные и премиальные.

## Слои

### UI
Jetpack Compose. Пользователь работает с одним поисковым полем и фильтрами «Все / Фото / Видео».

### Repository
`MediaRepository` объединяет результаты нескольких источников и скрывает детали API.

### Free providers
- Pexels
- Pixabay

Каждый источник вызывается независимо. Если один API недоступен, результаты другого не блокируются.

### Premium providers
Платные источники используют отдельный контракт `PremiumMediaProvider`.
Сейчас предусмотрены:
- Shutterstock
- Adobe Stock

Они отключены до получения и настройки официального API-доступа.

## Безопасность
API-ключи не должны попадать в Git. В текущем MVP они оставлены пустыми в `BuildConfig`. Для production нужно вынести вызовы API на backend.

## Ближайшая production-архитектура
`Android app -> Media Finder Backend -> Pexels / Pixabay / Shutterstock / Adobe Stock`

Backend сможет:
- скрывать API-ключи;
- кэшировать повторные запросы;
- объединять результаты;
- контролировать лимиты;
- применять единый формат лицензии и атрибуции;
- включать/отключать премиальные источники без выпуска новой версии APK.
